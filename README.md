# Certified Feed Service

Standalone TypeScript service for serving a certified Hypercerts feed from indexed data.

## Repository status

`main` intentionally contains the project scaffold only. The working implementation, tests, lexicons, deployment files, and operational documentation are developed on the `feed/standalone-mvp` branch.

The scaffold is not expected to build or run until the implementation branch is merged.

## Requirements

- Node.js 22 or newer
- npm

## Install

```bash
npm install
```

## Branches

- `main` — repository and TypeScript project configuration scaffold
- `feed/standalone-mvp` — standalone certified feed service implementation
